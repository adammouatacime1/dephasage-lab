# Captures de la page modèle du kit

Ces captures montrent **l’oscillateur de l’exemple**, distinct du laboratoire de diffraction d’origine. Elles sont produites par `npm run verify:browser` sur le résultat de `npm run build`, servi sous un sous-dossier, puis copiées ici comme aperçu du kit livré.

| Format | Clair | Sombre |
| --- | --- | --- |
| Ordinateur, fenêtre 1440 × 1000 | [Image](./desktop-light.png) | [Image](./desktop-dark.png) |
| Mobile, fenêtre 390 × 844 | [Image](./mobile-light.png) | [Image](./mobile-dark.png) |

Les images couvrent la page entière. Modèle initial au repos temporel `t = 0`, masse 1 kg, raideur 9 N/m et amplitude 0,6 m ; préférence système de réduction des mouvements activée, donc lecture initialement en pause. Chromium 154, rendu Canvas 2D, densité 1, sans retouche.

Les quatre références de **diffraction réelle** sont dans le [dossier parent](../README.md).
